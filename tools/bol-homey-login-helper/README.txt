Bol.com Homey Login Helper 0.3.1

1. Open chrome://extensions and enable Developer mode.
2. Remove/disable older Bol.com Homey Login Helper versions.
3. Choose Load unpacked and select this folder.
4. Open the helper and sign in to bol.com.
5. After login the helper automatically opens your bol.com orders overview to verify the account session and capture any Ampère tracking links returned by the page/network traffic.
6. Copy the generated BOLHOMEY3 session code.
7. Paste that code in the Ampère pairing/repair screen in MyParcel.

0.3.1 changes:
- Adds the supplied bol. icon to Chrome/the extension toolbar.
- Verifies the session against the authenticated bol.com orders page before showing a session code.
- Captures Ampère tracking URLs from the orders page and relevant network responses and includes them in the Homey session bundle.
- Keeps OAuth/access/refresh-token detection plus session-cookie fallback.
- Popup and result UI support all 13 MyParcel/Homey languages.

The AWS/Google Cloud CSP warnings that can appear in the bol.com DevTools console are generated by bol.com page telemetry being blocked by bol.com's own Content Security Policy. The helper does not request those hosts and does not need permissions for them.
