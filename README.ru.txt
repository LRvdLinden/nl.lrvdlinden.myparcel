MyParcel объединяет ваших перевозчиков посылок в Homey. Следите за всеми посылками в одном месте с помощью устройств, Flow и виджетов Homey. Приложение доступно на 13 языках.

Поддерживаемые перевозчики

- PostNL
- DHL (Нидерланды)
- DHL Express (международная доставка)
- Post & DHL (Германия)
- DPD
- UPS
- GLS
- FedEx
- Budbee
- Vinted Go (ранее Homerr)
- InPost (Великобритания, Польша, Италия, Португалия, Испания)
- bpost (Бельгия)
- Royal Mail (Великобритания)
- Ampère (Нидерланды)
- Trunkrs (Нидерланды)
- Dynalogic (Нидерланды, Бельгия)
- Dragonfly / Intelcom (Нидерланды, Австралия, Канада)
- Mondial Relay (Франция, Бельгия, Нидерланды, Испания, Португалия; нужна учётная запись)
- Amazon (экспериментально, 17 магазинов)

Установка

Инструкции по установке и подключению учётной записи для каждого перевозчика смотрите в теме MyParcel в сообществе Homey:
